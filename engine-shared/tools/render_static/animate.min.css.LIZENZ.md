# Animations-Baukasten: Herkunft

Eigene Implementierung von postmakr, kein Fremdcode. Die Datei übernimmt
bewusst die verbreitete Klassen-Konvention (animate__animated,
animate__fadeInLeft, ...), damit Anleitungen und Werkzeuge mit der bekannten
Schreibweise arbeiten können. Die Keyframes selbst sind von Grund auf neu
geschrieben (Standard-CSS).

Die Datei steht wie der Rest von postmakr lokal unter der AGPL-3.0 (siehe
LICENSE im Wurzelordner). Die bekannte Bibliothek mit derselben
Klassen-Konvention steht ab Version 4 unter einer Lizenz, die nicht
OSI-anerkannt ist, und wurde deshalb nicht verwendet.
