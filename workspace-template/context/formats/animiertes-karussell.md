# Format: animiertes-karussell (Platzhalter)

Noch keine Spec fuer dieses Format hinterlegt. Beim Ausfuellen mindestens
festhalten:

- Aufbau (Anzahl Slides/Sekunden, Reihenfolge der Inhalte)
- Bildformat/Aufloesung und Seitenverhaeltnis
- Pflichtelemente (Logo, Quellenzeile, CTA)
- Render-Weg (statisch/animiert, welches Tool)
